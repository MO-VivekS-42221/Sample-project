## 📚 Sample Database Setup

All guides use the same sample database:

### Students Table
```sql
CREATE TABLE students (
    student_id INT PRIMARY KEY AUTO_INCREMENT,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE,
    enrollment_date DATE,
    gpa DECIMAL(3, 2),
    department VARCHAR(50)
);
```

### Courses Table
```sql
CREATE TABLE courses (
    course_id INT PRIMARY KEY AUTO_INCREMENT,
    course_name VARCHAR(100) NOT NULL,
    course_code VARCHAR(10) UNIQUE,
    instructor VARCHAR(50),
    credits INT,
    semester VARCHAR(20),
    max_capacity INT
);
```

### Enrollments Table
```sql
CREATE TABLE enrollments (
    enrollment_id INT PRIMARY KEY AUTO_INCREMENT,
    student_id INT NOT NULL,
    course_id INT NOT NULL,
    grade CHAR(1),
    enrollment_date DATE,
    FOREIGN KEY (student_id) REFERENCES students(student_id),
    FOREIGN KEY (course_id) REFERENCES courses(course_id)
);
```

All examples in each guide use these consistent tables with sample data.

## 🤔 Frequently Asked Questions

**Q: Do I need to start with Beginner?**
A: If you already know SELECT/WHERE/JOINs, you can start with Intermediate. Otherwise, start at Beginner.

**Q: How long should I spend on each level?**
A: Follow the estimated time, but adjust based on your background and pace. Practice is more important than speed.

**Q: Can I skip topics?**
A: Not recommended. Each level builds on previous. Skipping will create gaps in understanding.

**Q: Should I memorize all functions?**
A: No. Memorize common ones, but you can always reference the guide. Focus on understanding concepts.

**Q: How do I practice if I don't have a database?**
A: Use free options: SQLite (local), MySQL (local), or online: SQLFiddle.com, DB-Fiddle.com, LeetCode SQL.

**Q: What's the best way to get better?**
A: Write queries for real problems, not just examples. Analyze their EXPLAIN plans. Optimize them. Repeat.
