# 09 - TestNG Interview Notes

## Very short revision notes
- TestNG = Next Generation testing framework for Java
- Used heavily with Selenium
- Key annotations: `@Test`, `@BeforeMethod`, `@AfterMethod`, `@BeforeClass`, `@AfterClass`
- `testng.xml` controls suite execution
- `@DataProvider` enables data-driven testing
- `@Parameters` passes values from XML
- `dependsOnMethods` creates test dependency
- Groups help organize smoke/regression suites
- Listeners track test events
- Retry analyzer reruns flaky tests
- Parallel execution reduces run time
- Page Object Model is best practice for Selenium + TestNG frameworks
